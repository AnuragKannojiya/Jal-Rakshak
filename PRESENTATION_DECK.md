6. Citizen tracks progress via timeline
7. Admin resolves with before/after photos
8. Dashboard analytics update in real-time
9. Citizen provides feedback on resolution

### 🟦 SLIDE 8 — SEVERITY ENGINE (Innovation)

**Title:** *"Our Innovation — Rule-Based Smart Priority"*

**Scoring Formula:**

```
  Base Score (by issue type)
  ┌───────────────────────────────┐
  │  Sewage Mixing      = 50     │
  │  Contamination      = 55     │
  │  Drainage Overflow   = 45     │
  │  Dirty Water        = 40     │
  │  No Water Supply    = 35     │
  │  Tanker Issue       = 30     │
  │  Broken Pipeline    = 25     │
  │  Leakage            = 20     │
  └───────────────────────────────┘

  + Modifiers:
    📸 Image attached        → +10
    🚰 Drinking water issue  → +15
    ⚡ High urgency          → +10
    📊 5+ complaints in area → +20
    📊 3+ complaints in area → +10

  = Final Score → Priority Level
    0-24: 🟢 Low | 25-49: 🟡 Medium | 50-74: 🟠 High | 75+: 🔴 Critical
```

**Example:**
> *"Sewage mixing (50) + drinking water (+15) + image (+10) + 5 reports in area (+20) = **95 → CRITICAL** 🔴"*

**Why this matters:**
> No AI/ML needed. Rule-based but intelligent. Works offline. Easy to explain to judges.

## 🎨 DESIGN GUIDELINES FOR PPT CREATION

### Color Palette
| Color | Hex | Usage |
|:---|:---:|:---|
| Deep Navy | `#023E8A` | Background, headers |
| Ocean Blue | `#0077B6` | Primary accent |
| Cyan | `#00B4D8` | Highlights, links |
| Light Sky | `#90E0EF` | Cards, backgrounds |
| White | `#FFFFFF` | Text, cards |
| Green | `#2DC653` | Safe / Success |
| Orange | `#FF8500` | Warning / Risky |
| Red | `#E63946` | Critical / Danger |

### Typography
- **Headings:** Poppins Bold or Montserrat Bold
- **Body:** Inter or Open Sans
- **Monospace:** JetBrains Mono (for code/scores)

### Slide Design Principles
- Clean, minimal layout — lots of whitespace
- One key idea per slide
- Use icons (Lucide or Heroicons style)
- Data > words — show numbers, charts, diagrams
- Consistent blue gradient branding throughout
- Subtle water-themed patterns in backgrounds
